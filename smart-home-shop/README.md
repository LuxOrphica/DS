# Smart Home Shop (local MVP)

Локальный MVP интернет-магазина оборудования для умного дома.

## Быстрый старт

```bash
cd f:\Projects\smart-home-shop
npm install
npm run start
```

Открыть: `http://localhost:3030`

## Что есть сейчас

- Каталог товаров по категориям и брендам.
- Карточка товара, галерея, характеристики, документы.
- Корзина и оформление заказа.
- Кабинет заказов.
- Админка для товаров/категорий/заказов.

## Проверка кодировки (обязательная)

Перед сдачей изменений обязательно проверяем кодировку и UI:

```bash
npm run encoding:check
npm run check:encoding-ui
```

Если найдены проблемы:

```bash
npm run encoding:fix
npm run check:encoding-ui
```

Полная проверка перед коммитом:

```bash
npm run verify
```

## Git hooks

В проекте есть pre-commit хук, который блокирует коммит при проблемах с кодировкой.
Установка:

```bash
npm run hooks:install
```

## Где смотреть данные

- Товары/заказы/каталог: `data/shop.db`
- Отчеты проверок: `reports/`

## Примечание

Все текстовые файлы проекта должны сохраняться в UTF-8. Использование shell-redirect (`>`/`>>`) для правки JS/HTML/CSS не допускается.
